# Weather Lookup

A browser-based weather exercise that accepts a city and country and displays the temperature in Fahrenheit using a weather API.

## Technology

HTML, CSS, JavaScript, OpenWeather API

## Run locally

Clone the repository, run `git switch answer`, then copy `js/config.example.js` to `js/config.js` and add your own OpenWeather API key. `js/config.js` is ignored by Git. Open `index.html` in a browser; internet access is required.

## Solution code

The completed implementation is on the `answer` branch. Switch to it with `git switch answer` after cloning.

[View the solution branch on GitHub](https://github.com/Nlewi-glitch089/weather-api-bootcamp/tree/answer).

This repository began as a Resilient Coders / bootcamp coding exercise. The original assignment prompt is preserved in the repository history; this README describes the implementation branch so visitors can understand what the code does and how to try it.
